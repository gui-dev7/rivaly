Run RIVALY from a local server

This project uses native ES Modules, which browsers refuse to load from file://. Start any static server in the project folder and reopen the page.

python -m http.server 5500
# then open http://localhost:5500

Settings

Preferences, local data and everything this build stores about you.

Account

This is a local academic simulation. There is no server, no password recovery and no synchronisation between devices.

Edit passport

Interface

Reduce motion

Disables animations, transitions and the reveal sequences. Your system preference is respected automatically; this forces it on.

Toast notifications

In-app feedback for XP, updates and errors. Achievement and level-up celebrations are not affected.

Compact density

Tightens spacing across the application. Useful on smaller laptops.

Local data

Everything RIVALY knows about you lives under the rivaly: namespace in this browser's local storage.

Reset demo data

Deletes your Passport, Gamer DNA, Library, achievements, activity and saved squad from this browser. Your sign-in account is kept so you can start over with the same email.

About this build

RIVALY V1 is built with HTML5, CSS3 and vanilla JavaScript only — no framework, no CSS library, no runtime dependency and no backend. Version 2 will remodel the same product using React and Tailwind CSS.
