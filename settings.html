Abra a RIVALY por um servidor local

Este projeto usa ES Modules nativos, que o navegador recusa carregar via file://. Suba qualquer servidor estático na pasta do projeto e reabra a página.

npm run dev
# ou: python -m http.server 5500

Convites e desafios

Configurações

Preferências, dados locais e tudo que esta versão guarda sobre você.

Conta

Editar meu Passaporte

Interface

Tema visual

Troca a paleta de toda a aplicação. A escolha fica salva neste navegador e vale para todas as páginas.

Tutorial guiado

Refaz o passo a passo por todas as áreas da RIVALY, do Passaporte à Arena, aos Clãs e ao Feed.

Reduzir animações

Desativa animações, transições e as sequências de revelação. A preferência do sistema já é respeitada automaticamente; aqui você força a opção.

Notificações

Avisos dentro do app para XP, atualizações e erros. As comemorações de conquista e de nível não são afetadas.

Densidade compacta

Reduz os espaçamentos em toda a aplicação. Útil em telas menores.

Dados locais

Tudo que a RIVALY sabe sobre você fica sob o namespace rivaly: no armazenamento local deste navegador.

Apagar dados e recomeçar

Apaga deste navegador o Passaporte, o DNA Gamer, a Biblioteca, as conquistas, a atividade, o squad salvo e toda a comunidade (clã, Arena, Feed, convites, sessões e relações). Sua conta de acesso é mantida, então você pode recomeçar com o mesmo e-mail.

Sobre esta versão

A RIVALY usa HTML5, CSS3, JavaScript em ES Modules e Bootstrap 5.3 servido localmente. Não há backend: a comunidade é simulada no seu navegador.
