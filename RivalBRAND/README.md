# Biblioteca de marca Rivaly

As imagens desta pasta foram classificadas por função visual. Todos os arquivos são PNG quadrados de 1254 x 1254 px, RGB e sem transparência; os fundos preto ou amarelo fazem parte da própria imagem.

## Identidade institucional

| Arquivo | Uso recomendado |
| --- | --- |
| `rivaly-logo-primary-symbol-yellow-dark.png` | Logo principal em hero, apresentação, capa e peças sobre fundo escuro. |
| `rivaly-logo-outline-symbol-yellow-dark.png` | Variação institucional leve para rodapé e materiais secundários. |
| `rivaly-logo-r-monogram-dark.png` | Assinatura compacta para cabeçalho e materiais institucionais. |
| `rivaly-logo-r-outline-yellow-dark.png` | Assinatura compacta secundária para peças escuras. |

## Hierarquia recomendada

- Principal: `rivaly-logo-primary-symbol-yellow-dark.png`.
- Compacta: `rivaly-logo-r-monogram-dark.png`.
- Ícone escuro: `rivaly-app-icon-rival-mark-yellow-dark.png` ou a versão arredondada.
- Ícone amarelo: `rivaly-app-icon-rival-mark-black-yellow.png`.
- Assets com `vs` devem ficar restritos a contextos de confrontos, partidas e comparações.

Estas imagens ainda não são referenciadas pelo HTML, CSS ou JavaScript do projeto. A integração deve escolher uma versão oficial por contexto para evitar inconsistência visual.
