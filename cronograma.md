# Futuras modificações

As fases abaixo estão ordenadas por dependência técnica e evolução do produto.

## Fase 1 — Fundação técnica, dados e autenticação

- [ ] Criar o backend com a lógica completa para adicionar amigos e enviar mensagens.
- [ ] Criar o banco de dados para armazenar:
    - [ ] Usuários e suas modificações no perfil.
    - [ ] Conquistas, XP e progresso em geral.
- [ ] Vincular contas Google ou Microsoft.
- [ ] Estruturar as APIs necessárias:
    - [ ] Steam CDN.
    - [ ] Chatbot.

## Fase 2 — Perfis e conexões sociais

- [ ] Implementar a edição completa do perfil:
    - [ ] Background.
    - [ ] Foto de perfil.
    - [ ] Jogo favorito.
    - [ ] Posição favorita.
    - [ ] Outras preferências do usuário.
- [ ] Adicionar biografia.
- [ ] Permitir a escolha de uma música para o perfil.
- [ ] Adicionar links de canais e outras redes sociais.
- [ ] Permitir a visualização de outros perfis, incluindo:
    - [ ] Amigos em comum.
    - [ ] Jogos em comum.
- [ ] Criar a lista de amigos.
- [ ] Adicionar feedback de amigos sobre jogo, role e o porquê.

## Fase 3 — Comunicação e recursos em tempo real

- [ ] Implementar a infraestrutura em tempo real.
- [ ] Exibir status ao vivo, incluindo:
    - [ ] Qual jogo a pessoa está jogando.
    - [ ] Há quanto tempo está jogando.
- [ ] Criar um lobby ao vivo entre amigos no site.
- [ ] Adicionar tradução automática ao chat entre pessoas de países diferentes.

## Fase 4 — Conteúdo, comunidade e avaliações

- [ ] Criar postagens e o feed da comunidade.
- [ ] Permitir a publicação de clipes de jogadas.
- [ ] Dividir o conteúdo entre:
    - [ ] Feed.
    - [ ] Highlights.
    - [ ] Conteúdo cômico.
- [ ] Adicionar avaliações de jogos no estilo Letterboxd.

## Fase 5 — Integrações com plataformas

- [ ] Vincular contas Steam, Riot, Epic e EA.
- [ ] Vincular contas Discord e Twitch.

## Fase 6 — Internacionalização e suporte inteligente

- [ ] Adicionar outros idiomas à plataforma.
- [ ] Criar um chatbot para responder dúvidas.
