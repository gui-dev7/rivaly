Abra a RIVALY por um servidor local

Este projeto usa ES Modules nativos, que o navegador recusa carregar via file://. Suba qualquer servidor estático na pasta do projeto e reabra a página.

python -m http.server 5500
# depois abra http://localhost:5500

Encontre seu squad
